A small follow-up to 0.2.0.

## Fixes

- **Fold the connected connection in the sidebar.** In the connections tree (Settings ▸ Interface ▸ Sidebar Layout ▸ "Connections tree"), clicking the connection you're connected to now folds and unfolds its tables, just like a folder. Clicking any other connection still switches to it.
- **The app icon is back.** The first 0.2.0 downloads showed a blank placeholder icon on macOS and a generic program icon on Windows. If you got one of those, this update puts the Tusk elephant back.

## Install

**macOS** (14 Sonoma or later, Apple Silicon): Tusk updates itself. Or download `Tusk-0.2.1-arm64.dmg` below, or run `brew upgrade tusk`.

**Windows** (x64 or ARM64): download the zip for your machine, unzip it, and run `Tusk.exe`. SmartScreen may warn the first time because the build isn't code-signed yet: click **More info ▸ Run anyway**.

**Linux** (x86_64): `.deb` for Ubuntu, `.rpm` for Fedora, `.pkg.tar.zst` for Arch, all below.

See [0.2.0](https://github.com/alpcanaydin/tusk/releases/tag/v0.2.0) for everything that came with Windows and Linux support.
